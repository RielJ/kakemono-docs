---
title: Where pictures come from
description: The websites and folders kakemono can take wallpapers from, and how to add one in Settings.
---

kakemono takes pictures from places called **sources**. A source can be a wallpaper website or a folder on your computer. You can have as many as you like, and kakemono mixes them.

## What you get without changing anything

A new install has three sources:

- **Wallhaven hot**: the wallpapers that are popular on [wallhaven.cc](https://wallhaven.cc) right now.
- **Wallhaven top**: the best-rated wallpapers on Wallhaven.
- **Favorites**: the pictures you marked with the heart.

## Sources you can add

| Source | What it gives you |
|---|---|
| Wallhaven | Wallpapers from wallhaven.cc for any search, such as *mountains* or *city night*. |
| Unsplash | Photos from unsplash.com for any search. Needs a free key, see below. |
| Reddit | Pictures posted to a subreddit, such as *EarthPorn*. |
| Bing | Bing's photo of the day. |
| APOD | NASA's Astronomy Picture of the Day. |
| Web page | The large pictures on any web page, gallery or feed. |
| Folders | Random pictures from a folder on your computer. |
| Images | Picture files you choose one by one. |

## Add a source

1. Open **Settings** from the kakemono icon.
2. Under **Images**, click **Add…**.
3. Choose a source, then fill in what it asks for: a search, a subreddit, a link or a folder.

kakemono checks the new source right away. If something is wrong, the source shows **Invalid**. Hover over the word to see why.

To stop using a source for a while, untick it. To remove it, select it and click **Remove…**.

## Use a search you made on the website

On Wallhaven, Reddit or Unsplash, search the way you like and set the filters. Then copy the link from the browser's address bar, and paste it as the source's location in Settings. kakemono uses the same search and filters.

For example, this Reddit link gives the month's top posts of r/EarthPorn:

```
https://www.reddit.com/r/EarthPorn/top/?t=month
```

## Unsplash needs a key

Unsplash asks every app to use its own free key.

1. Create an account at [unsplash.com/developers](https://unsplash.com/developers) and create an app there.
2. Copy its **Access Key**.
3. In kakemono, open **Settings** > **Advanced**, and paste it into **Unsplash access key**.

## Web pages that don't work

Some sites, such as Google Images, Pinterest and Instagram, build their pages in a way kakemono can't read. They show **Invalid**. Use a direct link to a picture instead.
