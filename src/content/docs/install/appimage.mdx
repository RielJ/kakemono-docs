The AppImage works on any Linux distribution and runs without installing. Download it:

<LinkButton href="https://github.com/RielJ/kakemono/releases/latest/download/kakemono-linux-x64.AppImage">Download the AppImage</LinkButton>

Then make it runnable and start it, from the folder you downloaded it to:

```sh
chmod +x kakemono-linux-x64.AppImage
./kakemono-linux-x64.AppImage
```

The AppImage doesn't add kakemono to your app launcher. Start it the same way next time, or use the [.deb](/install/debian/) or [.rpm](/install/fedora/) package if your system takes one.
