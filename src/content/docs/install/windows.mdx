title: Install on Windows

---

import { Steps, LinkButton } from '@astrojs/starlight/components';
import FirstOpen from '../../../components/install/FirstOpen.mdx';

<Steps>

1. Download the installer:

   <LinkButton href="https://github.com/RielJ/kakemono/releases/latest/download/kakemono-windows-x64-setup.exe">Download for Windows</LinkButton>

2. Open the downloaded file. Windows shows a blue box that says **Windows protected your PC**.

   kakemono isn't signed with a paid certificate yet, so Windows doesn't know who published it. Click **More info**, then click **Run anyway**. You only do this once.

3. Follow the installer.

4. Open kakemono from the Start menu. Its icon appears in the system tray, at the bottom right of your screen. If you don't see it, click the **^** arrow next to the clock.

</Steps>
