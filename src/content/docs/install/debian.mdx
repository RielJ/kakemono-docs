Download the package and open it to install it with your software center:

<LinkButton href="https://github.com/RielJ/kakemono/releases/latest/download/kakemono-linux-x64.deb">Download the .deb</LinkButton>

Or install it from a terminal:

```sh
curl -LO https://github.com/RielJ/kakemono/releases/latest/download/kakemono-linux-x64.deb
sudo apt install ./kakemono-linux-x64.deb
```

Then open **kakemono** from your app launcher.
