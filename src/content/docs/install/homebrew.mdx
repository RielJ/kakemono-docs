On a Mac with [Homebrew](https://brew.sh), paste this into Terminal and press **Return**:

```sh
brew install --cask rielj/tap/kakemono
```

Homebrew tells macOS the app is safe, so you skip the "damaged" warning. Open kakemono from Applications. Its icon appears in the menu bar, at the top right of your screen.

Don't have Homebrew? [Download the app](/install/mac/) instead. On Linux, Homebrew installs only the command-line tool; see [Other ways to install](/install/other/#command-line-tool-only).
