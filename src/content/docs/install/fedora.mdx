Download the package and open it to install it with your software center:

<LinkButton href="https://github.com/RielJ/kakemono/releases/latest/download/kakemono-linux-x64.rpm">Download the .rpm</LinkButton>

Or install it from a terminal:

```sh
# Fedora
sudo dnf install https://github.com/RielJ/kakemono/releases/latest/download/kakemono-linux-x64.rpm

# openSUSE
curl -LO https://github.com/RielJ/kakemono/releases/latest/download/kakemono-linux-x64.rpm
sudo zypper install ./kakemono-linux-x64.rpm
```

Then open **kakemono** from your app launcher.
