## What it does

<CardGrid>
	<Card title="Many sources" icon="seti:image">
		Wallhaven and Unsplash searches, subreddits, Bing's daily images, NASA's archive back to
		1995, any web page or RSS feed, and your own folders. Paste a search URL from Wallhaven,
		Reddit or Unsplash and kakemono uses its filters.
	</Card>
	<Card title="A picker" icon="seti:folder">
		A strip of thumbnails along a screen edge. Browse a source without downloading anything,
		then click the one you want. Every action has a key.
	</Card>
	<Card title="History" icon="random">
		Step back to the last wallpaper, keep the good ones as favorites, and trash the ones you
		never want to see again.
	</Card>
	<Card title="Scriptable" icon="seti:shell">
		One binary is the daemon and the command-line tool. Bind `kakemono next` to a key, run a
		hook on every change, or talk JSON to its socket.
	</Card>
</CardGrid>

It asks before it changes anything. A new install doesn't touch your wallpaper until you click
**Change wallpaper now**, press **Next** in the tray, or turn on the timer in Settings.

## Install

<Tabs syncKey="os">
	<TabItem label="macOS">
		```sh
		brew install --cask rielj/tap/kakemono
		```
		Or download the `.dmg` from the [install page](/getting-started/install/#macos).
	</TabItem>
	<TabItem label="Windows">
		```powershell
		scoop install https://raw.githubusercontent.com/RielJ/scoop-bucket/main/bucket/kakemono.json
		```
		Or run the [installer](/getting-started/install/#windows).
	</TabItem>
	<TabItem label="Linux">
		```sh
		# Debian, Ubuntu
		curl -LO https://github.com/RielJ/kakemono/releases/latest/download/kakemono-linux-x64.deb
		sudo apt install ./kakemono-linux-x64.deb
		```
		Fedora, the AppImage and ARM are on the [install page](/getting-started/install/#linux).
	</TabItem>
</Tabs>

## Works on your desktop

On macOS and Windows, kakemono sets the wallpaper through the system's own API, with no extra
permissions. Linux has no single API, so kakemono looks at your session and picks one of 17
backends, such as GNOME, KDE Plasma, XFCE, Sway, `hyprpaper`, `swww`, `swaybg` and `feh`. That
covers the big desktops and tiling compositors like Hyprland and niri. `kakemono detect` tells
you which backend it chose and why.
